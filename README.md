# Hanbing Liu's Homepage

Personal academic website with research, publications, awards, and academic service.

## Files

- `index.html`: homepage content.
- `new.css`: homepage styles.
- `images/`: profile photo and publication figures.
- `data/`: CV and publication posters linked from the homepage.
- `_config.yml`: GitHub Pages configuration.

## Local preview

Run `python3 -m http.server 8000` from this directory, then open
<http://localhost:8000>.
